LETAKKAN LOGO INSTITUSI DI FOLDER INI
======================================

Nama berkas (salah satu, urut prioritas pembacaan):
  1. logo.svg   (disarankan — tajam di segala ukuran)
  2. logo.png   (alternatif; latar transparan)
  3. logo.webp
  4. logo.jpg / logo.jpeg

Spesifikasi:
  - Bentuk persegi/square, idealnya 512x512 px (atau SVG vektor)
  - PNG sebaiknya berlatar transparan
  - Hindari logo berbentuk sangat lebar (landscape) — akan kecil di sidebar

Tidak perlu mengubah kode apa pun. Begitu berkas diunggah dengan nama di
atas, logo otomatis tampil pada:
  - Sidebar (kotak putih kecil, ±32 px)
  - Halaman masuk / login (±58 px)
  - Ikon tab browser (favicon)

Bila berkas belum ada, aplikasi memakai ikon perisai bawaan (sama seperti
tampilan sekarang).

Alamat folder:  C:\xampp\htdocs\lpm\public\assets\img\
Akses web:      http://localhost/lpm/public/assets/img/
